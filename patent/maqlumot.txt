════════════════════════════════════════════════════════
2. ТЕХНИЧЕСКАЯ АРХИТЕКТУРА
════════════════════════════════════════════════════════

Frontend:
  • Next.js 14 (App Router), React 18, TypeScript
  • Tailwind CSS 3 (токены светлой/тёмной темы)
  • axios + JWT-interceptor, WebSocket-клиент
  • Страницы: /, /jobs, /jobs/[id], /companies, /applications,
    /favorites, /recommendations, /chat, /notifications,
    /settings, /profile/{student,employer}, /employer/*,
    /auth/*, /pricing, /blog, /about, /contact, /help

Backend (FastAPI, async):
  • main.py — приложение, CORS, WebSocket /ws/notifications/
  • routes_auth.py    — register, login, refresh, Google OAuth
  • routes_jobs.py    — CRUD вакансий/резюме/откликов, статистика
  • routes_misc.py    — избранное, уведомления, чаты, сообщения
  • routes_users.py   — профили, смена пароля, экспорт данных
  • routes_ai.py      — AI-резюме, рекомендации вакансий
  • routes_parser.py  — парсинг somon.tj, remotive, arbeitnow
  • routes_payments.py— тарифы, оплата, подписки
  • routes_extras.py  — PDF, геокодинг, верификация email
  • rate_limit.py     — защита от перебора (120/20 req/min)

База данных (SQLAlchemy async, SQLite/PostgreSQL):
  users, student_profiles, employer_profiles, categories,
  work_schedules, work_formats, work_experiences, resumes,
  jobs, applications, favorites, notifications,
  notification_preferences, chat_sessions, chat_messages,
  direct_messages, email_verifications, password_reset_tokens,
  tariff_plans, user_subscriptions, payments

Безопасность:
  • bcrypt-хеширование паролей
  • JWT HS256: access 60 мин, refresh 7 дней
  • Google OAuth 2.0 (openid email profile)
  • Rate limiting по IP (фиксированное окно)
  • Проверка владения ресурсом в каждом эндпоинте

════════════════════════════════════════════════════════
3. КЛЮЧЕВЫЕ ФУНКЦИИ (ИНОВАЦИИ)
════════════════════════════════════════════════════════

1.  AI-подбор вакансий (match_score на основе резюме)
2.  AI-генерация резюме + чат-корректор резюме (Gemini API)
3.  Парсинг вакансий с 4 внешних источников + планировщик
4.  Отклики со статусами: sent → viewed → interview →
    accepted / rejected (+ WebSocket-уведомления)
5.  Избранное (избранные вакансии) с синхронизацией
6.  Уведомления: REST + непрочитанный счётчик + WebSocket
7.  Личные сообщения студент↔работодатель + AI-консультант
8.  PDF-экспорт вакансии и резюме (4 стиля оформления)
9.  Геолокация вакансии (Google Maps) + построение маршрута
    (OSRM) от места проживания до работы
10. Просмотр профиля/вакансии (views_count) и сводка
    аналитики работодателя (конверсия просмотр→отклик)
11. Настройки уведомлений (email/push) с сохранением
12. Смена пароля и экспорт всех данных пользователя (JSON)
13. Горячие клавиши (? — справка), хлебные крошки,
    прогресс чтения, кнопка «Наверх»
14. Многоязычность (ru/tj/en), светлая/тёмная/системная тема
15. Тарифы Free/Pro/Premium, создание платежей, проверка доступа

════════════════════════════════════════════════════════
4. ПРИМЕР СЦЕНАРИЯ ИСПОЛЬЗОВАНИЯ
════════════════════════════════════════════════════════

Студент → регистрация → заполняет профиль и резюме
       → ИИ рекомендует 5 вакансий с match_score
       → отклик в 1 клик (+ сопроводительное письмо)
       → push-уведомление при смене статуса
Работодатель → создаёт вакансию → видит просмотры и отклики
       → меняет статус → кандидат получает уведомление
       → переписка в чате → подписание на тариф Pro
