────────────────────────────────────────────────────────
2. КРАТКАЯ ПРОГРАММА ДЕЙСТВИЙ (BARNOMA)
────────────────────────────────────────────────────────

Этап 1. Подготовка материалов
  1.1 Собрать фронтенд:     cd Frontend && npm run build
  1.2 Проверить бэкенд:     cd Backend && pip install -r requirements.txt
  1.3 Сформировать БД:      python -c "import asyncio; from database import init_db; asyncio.run(init_db())"
  1.4 Скопировать артефакты на flash-card по структуре из п.1

Этап 2. Подача в Госкомитет
  2.1 ariza.txt          — заявление установленного образца
  2.2 savolname.txt      — опросник (выдаётся в Госкомитете)
  2.3 boji_davlat.txt    — квитанция об уплате госпошлины 1000 сомони
  2.4 flash-card (1 шт.) — с программой из п.1
  2.5 presentaciya.pdf   — цветная печать презентации (по желанию)
  2.6 maqlumot.txt       — полная информация о программе

Этап 3. Регистрация
  3.1 Приём документов и проверка комплектности
  3.2 Экспертиза заявки
  3.3 Выдача Шаходатномаи (свидетельства) о государственной
      регистрации программы для ЭВМ

────────────────────────────────────────────────────────
3. ТЕХНИЧЕСКОЕ ОПИСАНИЕ ПРОГРАММЫ (КРАТКО)
────────────────────────────────────────────────────────

Назначение:   Подбор вакансий и резюме с помощью ИИ (Gemini API)
Стек:         FastAPI, SQLAlchemy, PostgreSQL/SQLite, Next.js 14,
              React 18, TypeScript, Tailwind CSS, WebSocket
Аутентификация: JWT (access 60 мин / refresh 7 дней) + Google OAuth 2.0
Ключевые модули:
  • Парсинг вакансий (somon.tj, remotive, arbeitnow, himalayas)
  • AI-генерация резюме и рекомендации вакансий с match_score
  • Отклики на вакансии со сменой статуса (sent→…→accepted/rejected)
  • Избранное, уведомления (REST + WebSocket), чаты (AI + личные)
  • Тарифы/подписки, PDF-экспорт резюме и вакансий
  • Rate limiting, просмотр профиля/вакансии, аналитика работодателя
